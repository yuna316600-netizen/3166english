# 영어 단어 시험 웹앱 (Gemini AI 최신 모델 연동)

영단어를 입력하고 **`[✨ 제미나이로 뜻·예문 자동 완성]`** 버튼을 누르면, **Google Gemini AI(`gemini-2.5-flash`)**가 단어의 모든 주요 품사별·의미별 뜻과 자연스러운 실전 영어 예문(한국어 해석 포함)을 자동으로 생성하여 입력해 주는 영어 단어 암기 학습 웹 애플리케이션입니다.

---

## 🌟 Gemini API 연동 최적화

1. **최신 표준 모델 엔드포인트 적용**:
   * Google의 최신 표준 모델인 **`gemini-2.5-flash`**(`https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent`)를 기본 호출 엔드포인트로 설정하였으며, 키 환경에 따라 `gemini-1.5-flash`로 자동 폴백을 지원합니다.
2. **API 키 실시간 저장 및 앞뒤 공백(trim) 완전 제거**:
   * API 키를 복사해 붙여넣거나 입력하는 즉시 앞뒤 공백을 자동으로 잘라내어(`trim`) `localStorage`에 실시간 저장하므로, 별도 저장 버튼을 누르지 않아도 곧바로 정확하게 사용됩니다.
3. **구체적인 오류 원인 표시**:
   * API 호출이 실패할 경우(잘못된 키, 쿼터 초과, 권한 오류 등) 단순히 일반 실패 문구를 띄우는 것이 아니라, Google API가 반환하는 **구체적인 HTTP 상태 코드(예: HTTP 400, 403, 429) 및 오류 상세 메시지**를 화면 상태 표시줄과 알림 팝업으로 즉시 안내합니다.

## 💻 실행 방법

별도의 서버 설치 없이 브라우저에서 바로 사용할 수 있습니다:

1. 브라우저에서 [index.html](file:///Users/jeong-yun-a/.gemini/antigravity/scratch/vocab-quiz-app/index.html) 파일을 엽니다.
2. 우측 상단의 **`[⚙️ API 키 설정 (선택)]`**을 눌러 본인의 Gemini API 키를 입력하면 즉시 자동 저장됩니다. (공백은 자동으로 제거됩니다.)
3. 영단어 입력 후 **`[✨ 제미나이로 뜻·예문 자동 완성]`**을 누르면 모든 주요 뜻과 예문/해석이 자동으로 채워집니다.
4. 만약 오류가 발생할 경우 정확한 HTTP 상태 코드와 오류 사유가 알림창으로 표시됩니다.
